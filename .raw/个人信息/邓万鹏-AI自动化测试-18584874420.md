## 开源代表作

### ai-api-test-skill ｜ AI接口自动化测试 SKILL ｜ GitHub 100+ Star / 10+ Fork

- **项目地址：** https://github.com/buer2233/ai-api-test-skill
- **方法沉淀：** 将测试人员日常的接口分析、用例编写、问题排查与执行验证经验沉淀为 AI SKILL；通过任务前置门禁、编码规范、接口查重和 pytest 强制验证，约束 AI 按既定流程交付可运行、可验证的用例。
- **技术实现：** 通过让AI获取抓包真实接口、参考历史用例、cURL接口信息或Jacoco覆盖率报告等上下文信息，并依据编码规范和各种强制要求，引导AI快速且规范的编写接口自动化测试用例。
- **工程化闭环：** 通过 SQLite 建立接口索引，实现接口查重与快速定位；以 pytest 形成“编写 - 执行 - 修复”闭环，降低自由生成代码带来的随机性、重复实现和不可运行问题。
- **落地与进展：** 已提交公司 GitLab 自动化测试仓库并投入内部团队使用。以本人负责的 EB 低代码模块为样本，AI 使用前后各统计7周，新增接口自动化用例由 **438 条提升至674条**，增加236条，阶段性效率提升约 **50%**。

### 项目：泛微 E10 数字化运营平台 - e-Builder 低代码平台

**项目背景：** 泛微网络是协同办公 OA 上市公司，传统OA行业的龙头企业。泛微E10是基于eteams平台全新研发的数字化运营构建平台，融合E9产品功能，采用分布式微服务架构，适配主流关系型数据库，支持云端和私有化部署。

**负责模块：** e-Builder：表单、页面、报表、应用、菜单等低代码平台模块；数据仓库：数据连接、数据抽取、数据视图等模块。

### 工作职责与技术实践

- 参与需求评审和测试方案梳理，分析接口与前端 UI 变更，设计测试点、准备测试数据并推进缺陷闭环。
- 搭建、维护接口与 UI 自动化测试框架；基于 pytest 组织测试执行和报告，持续优化异常定位、报告信息与框架稳定性。
- 基于 DRF+Vue 参与测试平台开发，覆盖接口自动化、UI 自动化、性能测试、日志错误检查，以及缺陷管理、接口覆盖率和自动化用例统计等能力。
- 作为部门内的AI+测试的先行者，始终保持极高的敏感度去调研，并应用最新最有价值的AI技术到我们的测试工作中。

### AI测试与自动化实践（链接附带详细信息信息）

自动化建设遵循测试金字塔：在项目成型后的补测阶段，优先快速建立接口自动化质量底座；在核心链路稳定后，以 UI 冒烟与高频问题场景补齐用户路径；再通过测试平台、报告分析和 AI 能力持续提升回归效率与覆盖质量。

- **2022年 - 快速建立接口质量底座：** 项目已进入补测阶段，优先覆盖后端接口以快速保护常用功能与关键流程；全年新增 **1217** 个接口用例、覆盖 **1626** 个接口方法，推动 e-Builder 接口覆盖率从 **30% 提升至90%**。在接口覆盖基础上补充 **92** 个重要 UI 用例作为核心链路冒烟，兼顾执行速度与端到端可用性。
- **2023年 - 加深核心流程的接口覆盖和测试平台开发：** 持续补齐核心业务接口的深度和广度，并通过开发的测试平台，定时任务执行接口自动化、重要基线执行 UI 冒烟。本人负责模块全年通过自动化反馈并跟踪 **462 个问题**，月均约 **38 个**，将快速迭代阶段的问题前移至测试环节。
- **2024年 - 项目稳定迭代后调整补充重点UI覆盖：** 项目进入固定版本迭代后，接口业务场景已较完整，客户反馈更多集中在前端交互和高频使用场景；新增 **728** 个接口用例、**350** 个 UI 用例，围绕常规前端流程和客户问题高发场景补齐 UI 自动化。通过接口与 UI 自动化提前发现并推动修复 **131 个问题**，并支持基线、Beta、升级包/安装包等多环境交付验证。
- **2025年 - 评估 AI + UI 自动化的适用边界：** 随着 UI 覆盖扩大，基线发布时的报告分析、问题提交和用例维护成本上升；调研并二开 browser-use，结合低代码平台与 Jenkins 进行 AI + UI 自动化试点。验证结果表明，自然语言用例可降低部分维护成本，但在复杂场景中仍面临执行耗时、稳定性和结果一致性挑战，因此保留 Selenium 作为复杂核心场景的主方案，明确 AI + UI 自动化的适用边界。
- **2026年 - 用 AI SKILL 提升接口用例交付效率：** 在 UI 覆盖趋于稳定后，减少了低价值 UI 扩张，UI用例聚焦高频问题场景。在Vibe Coding和各种编程工具，编程大模型的崛起背景下，我结合 Vibe Coding 和日常编写接口用例的经验，将编写用例的提示词升级为带任务门禁、接口索引、查重与 pytest 验证的接口测试 SKILL。该方案已在内部团队使用，也就是我GitHub开源100+Star的项目，并且效率提升明显。

**负责模块：**

**项目职责与实践：**
